# Tic-Tac-Toe Game 🎮

A Tic-Tac-Toe game built using Python and Object-Oriented Programming (OOP).

## 📌 About the Project

This project is part of my Python learning journey.
It helped me practice designing a game using classes and objects.

## 🚀 Features

- Two-player gameplay
- Interactive game board
- Player symbol management
- Win detection
- Draw detection
- Replay or quit options

## 🛠️ Technologies Used

- Python
- Object-Oriented Programming (OOP)

## ▶️ How to Run

1. Make sure Python is installed.
2. Clone this repository.
3. Open the project directory.
4. Run:

   python main.py

## 📚 What I Learned

- Classes and objects
- Constructors (`__init__`)
- Instance attributes and methods
- Organizing code into modules
- Implementing game logic
- Managing player turns
